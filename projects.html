osint-domain-recon

A command-line Python tool for automated domain reconnaissance. Given a target domain, it pulls WHOIS registration data, enumerates DNS records, resolves IP addresses, and probes HTTP/HTTPS availability. All in one run, with optional plaintext report export.

windows-log-analyzer

A browser-based parser for Windows Event XML exports, IIS W3C logs, and plain text log files. Drop in a file and get instant level-breakdown stats, a severity donut chart, full-text search with keyword highlighting, Event ID and severity filters, and one-click CSV or JSON export. Everything runs client-side. No data leaves the browser.
