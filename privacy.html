Legal

Privacy Policy

Last updated July 3, 2026.

Overview

ThreatVector762 Labs (operated by Ryan Jorgensen) runs threatvector762.dev as a static site with no server-side backend. There's no database, no user accounts, and no way for this site to store anything a visitor submits, because there's nothing running behind it capable of storing it.

Hosting

This site is hosted on GitHub Pages. GitHub, as the host, independently collects standard connection data from anyone visiting any GitHub Pages site, including things like IP address and browser type, as part of running its own infrastructure. That collection is governed by GitHub's own privacy statement, not by anything configured on this site. See GitHub's General Privacy Statement for details.

Cookies and tracking

This site doesn't set cookies, run analytics, or load tracking scripts of any kind. If that changes, this page gets updated before the change goes live, not after.

Contact

Reaching out through the contact page sends a message directly to Ryan's inbox. There's no form backend, no third-party service, and no logging on this end. Whatever you send exists only in that email conversation.

Children's privacy

This site isn't directed at children and doesn't knowingly collect information from anyone, regardless of age, because it doesn't collect information from anyone in the first place.

Changes to this policy

This page may be updated as the site changes. The date at the top reflects the current version.
