osint-domain-recon

A command-line Python tool for automated domain reconnaissance. Given a target domain, it pulls WHOIS/RDAP registration data, enumerates DNS records, resolves IP addresses, probes HTTP/HTTPS availability, and runs SPF/DMARC/DKIM/BIMI email-authentication checks — all in one run, with optional plaintext report export.

windows-log-analyzer

A browser-based parser for Windows Event XML exports, IIS W3C logs, and plain text log files. Instant level-breakdown stats, a severity donut chart, full-text search with keyword highlighting, Event ID and severity filters, and one-click CSV/JSON export. Everything runs client-side — no data leaves the browser.
