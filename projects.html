osint-domain-recon

A command-line Python tool for automated domain reconnaissance. Given a target domain, it pulls WHOIS registration data, enumerates DNS records, resolves IP addresses, and probes HTTP/HTTPS availability -- all in one run, with optional plaintext report export.
